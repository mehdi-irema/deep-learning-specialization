# Deep Learning Specialization (DeepLearning.AI)

My completed programming assignments from the five-course [Deep Learning Specialization](https://www.coursera.org/specializations/deep-learning) by Andrew Ng. They go from building neural networks from scratch in NumPy to CNNs, sequence models and Transformers in TensorFlow/Keras.

| Course | Assignments |
|---|---|
| **1. Neural Networks and Deep Learning** | Python and NumPy basics · logistic regression as a neural network · planar data classification with one hidden layer · deep neural network step by step · deep network application (cat vs non-cat) |
| **2. Improving Deep Neural Networks** | Initialisation · L2 and dropout regularisation · gradient checking · optimisation methods (momentum, RMSProp, Adam, learning-rate decay) · introduction to TensorFlow |
| **3. Structuring Machine Learning Projects** | Case studies (no programming assignments) |
| **4. Convolutional Neural Networks** | Convolution step by step · CNN application · residual networks (ResNet-50) · transfer learning with MobileNet · YOLO car detection · U-Net image segmentation · face recognition (FaceNet) · neural style transfer |
| **5. Sequence Models** | RNN and LSTM step by step · character-level language model · jazz improvisation with an LSTM · word-vector operations and debiasing · emojifier · neural machine translation with attention · trigger-word detection · Transformer from scratch · Transformer applications (NER, extractive QA) |

**Tools:** Python, NumPy, TensorFlow/Keras, Jupyter

> These are course assignments. The notebook scaffolding comes from DeepLearning.AI, and the implementations are mine.
